# Room 3D project instructions

- Run local development and preview servers with host `0.0.0.0`, so the host machine and other devices can access this VM over its network address. Do not bind these servers only to `localhost` or `127.0.0.1`.
- Share the VM's network URL and port when reporting a running server. `0.0.0.0` is the bind address, not the address to open in a browser.
